# kelp-ledger

A tiny shipment ledger for an invented seaweed co-op. Plain Node, no dependencies.

- `src/money.js`: amounts, kept in whole cents.
- `src/ids.js`: identifiers.
- `src/manifest.js`: reading a courier's manifest over HTTP.
- `src/log.js`: log lines.
- `src/shipments.js`: shipment lists.
- `src/weights.js`: parcel weights.

Run the tests with `node --test`.
