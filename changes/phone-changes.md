Review a session's work on your phone: Mesa's iPhone app opens a session's changes file by file with lines added and removed, pages through a large diff as you scroll, and sends a note on the lines you tap, or on a passage of a reply, to its agent through the guardrail. It also stages, commits (with a message you type or one an agent writes), pulls, pushes and switches branch, and browses, searches and previews the session's files.
