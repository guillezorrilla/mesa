Cloud Logs: a Logs tab in the sidebar reads Google Cloud Logging for all your GCP projects with your own `gcloud` sign-in. It opens on Error Reporting's error groups, leaves load balancer and system noise out, lets you explore entries by service, field and trace, and answers questions in a conversation that cites the entries it used and can start a session to fix an error; set it up in the tab, picking projects from a list filtered as you type and envs suggested from your GKE clusters and Cloud Run services, or with `mesa logs setup`.
