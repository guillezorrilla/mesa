Logs panel: a session with a project gets a Logs button that shows its local servers' output live, however they run (Docker containers, server sessions, a JetBrains IDE's console, any terminal through `mesa logs run`, or a log file anywhere), folds stack traces to your own code, filters to one request from its id, groups identical errors, mutes noisy lines, and sends the lines you pick to the agent to explain or fix, or starts a session with them; it can take the whole session area, and a project can hide it.
