Logs panel: a session with a project gets a Logs button that shows its local servers' output live (Docker containers, server sessions, or an IntelliJ console saved to a file in four guided steps) with each source's state, folds stack traces to your own code, filters to one request from its id, groups identical errors, mutes noisy lines, and sends the lines you pick to the agent to explain or fix, or starts a session with them; a project can hide it.
