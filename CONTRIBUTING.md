# Contributing

Thanks for your interest in Mesa.

## Issues are welcome

Bug reports and feature requests are welcome as [GitHub issues](https://github.com/guillezorrilla/mesa/issues/new/choose). Search the open issues first, and use the bug template so the report has the version, the steps, and the logs. Security problems go through [SECURITY.md](SECURITY.md), never a public issue.

## Pull requests

Pull requests from outside the project are not accepted for now. Mesa is built by its owner with coding agents, under the rules in [AGENTS.md](AGENTS.md), and every change follows an issue the owner has written and labelled `ready`. If you have a fix, open an issue that describes it; a pull request from outside is closed without review.

## Building from source

See [Building from source](README.md#building-from-source) in the README. `pnpm verify` (lint, typecheck, test, build) must pass.
